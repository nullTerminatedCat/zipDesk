# 青匣 v0.2.0 预览版

本版聚焦界面和浏览体验。Windows x64 / x86 使用同一份源码，均提供安装包和免安装 ZIP。

## 更新内容

- 更新首页、文件列表、进度弹窗的视觉层次、字体和间距。
- 最近记录显示文件名及目录，便于区分同名压缩包。
- 文件名称列自动适应窗口；长路径省略显示并保留完整提示，可右键复制压缩包路径。
- 新增 Ctrl+F 搜索、Esc 清除、Ctrl+N 新建；搜索无结果提供明确提示和清除入口。
- 区分空包与无匹配结果，并保留空状态区域的文件拖放。
- 改善最小窗口和 150% 缩放布局。
- 相比原 v0.1.0 x64 包，增加移动确认、写入后大小/CRC 核对及失败/取消反馈，修正任务完成与列表刷新时序。
- 包内附带项目 MIT LICENSE 与第三方许可；程序文件属性提供版本号。

## 下载

- `QingXia-0.2.0-windows-x64-setup.exe` / `QingXia-0.2.0-windows-x86-setup.exe`：安装包。
- `QingXia-0.2.0-windows-x64-portable.zip` / `QingXia-0.2.0-windows-x86-portable.zip`：完整解压后运行 `ZipDesk.exe`，包含所需运行库。
- `SHA256SUMS.txt`：四个安装包与 ZIP 的 SHA-256 校验值。

## 验证与限制

- x64、x86 各 19 项 CTest 通过；主窗口 150% 缩放专项通过。
- 两种架构的免安装包均在仅系统 PATH 下验证创建、完整性校验、解压和文件内容一致性。
- x86 使用源码编译的 Qt 6.9.1；验证环境为 64 位 Windows 的 32 位运行环境，未在原生 32 位 Windows 上验收，不是 Windows 7 兼容版本。
- 安装包尚未完成干净系统上的安装、升级、卸载与文件关联全流程验收；程序未做代码签名。
- RAR 只读；部分英文文案、批量工作流和逐项冲突结果仍待完善。取消或失败可能保留部分输出，已覆盖文件不会自动恢复。
