# 青匣 v0.2.1 预览版

本版改进压缩设置与任务进度体验，提供 Windows x64 / x86 安装包和免安装 ZIP。

## 更新内容

- 压缩窗口优先展示格式和保存位置，密码、压缩级别、分卷等收进高级选项；已有高级设置会自动展开。
- 输入错误在窗口内提示并聚焦出错字段，修改后清除提示；密码错误自动展开高级选项。
- 未知总量显示等待进度，修复大数据量进度计算溢出。
- 取消请求只发送一次，等待停止期间保持取消状态，下次任务可正常复用窗口。

## 下载

- 文件名含 x64：64 位 Windows；含 x86：32 位程序。
- setup.exe 为安装包；portable.zip 完整解压后运行 ZipDesk.exe。
- SHA256SUMS.txt 包含四个发布包的 SHA-256 校验值。
- 包含 Qt、7-Zip、Visual C++ 运行库及项目 MIT 和第三方许可证。

## 验证与限制

- x64 / x86 各 20 项 CTest 通过，包含输入校验、高级设置和进度取消回归；错误状态窗口截图已检查。
- x86 使用源码编译的 Qt 6.9.1，在 64 位 Windows 的 WOW64 环境验证，未在原生 32 位 Windows 验收，不是 Windows 7 兼容版本。
- 程序未签名；干净系统的安装、升级、卸载和文件关联全流程尚未完成验收。
- 解压逐项冲突、实际结果清单、速度及剩余时间等后续工作仍在推进。取消或失败可能保留部分输出，已覆盖文件不会自动恢复。
