# 青匣 v0.2.10

## 本版改进

- 设置页新增「使用 Windows 10 经典右键菜单」开关：在 Windows 11 上将资源管理器右键菜单改回 Windows 10 经典样式，也可一键改回新菜单。
- 仅修改当前用户注册表（HKCU），不需要管理员权限；非 Windows 11 时该项灰掉并说明原因。
- 更改后提示需要重启资源管理器，并提供「立即重启资源管理器」按钮；重启时任务栏会短暂消失，已打开的文件夹窗口通常会自动恢复。

## 验证

- x64 / x86 构建与 CTest 全通过。
- 注册表读写往返测试覆盖启用、关闭与状态恢复；设置页校验开关存在且在 Windows 11 上可交互。
