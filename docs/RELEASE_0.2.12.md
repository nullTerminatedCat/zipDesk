# 青匣 v0.2.12

真正支持读取 TAR、GZIP，以及常见的 `.tar.gz` / `.tgz`：

- 打开 `.tar` 可浏览并解压其中的文件与目录。
- 打开 `.gz` 可解压其中的单个文件。
- 打开 `.tar.gz` / `.tgz` 会先展开内层 TAR，再列出并解压其中的成员（与直接打开 `.tar` 相同的使用方式）。
- TAR / GZIP / TAR.GZ 与 RAR 一样只读：可打开、解压、测试；不可创建或就地修改。
- XZ、ISO、ZIPX 仍明确提示暂不支持。
- 首页与打开对话框文案/过滤器已包含 TAR / GZ。

x64 / x86 各 31 项 CTest 通过。
