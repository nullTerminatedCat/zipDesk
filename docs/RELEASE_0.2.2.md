# 青匣 v0.2.2 预览版

继续完善第二阶段压缩与解压体验，提供 Windows x64 / x86 安装包及免安装 ZIP。

## 更新内容

- 同名冲突窗口新增冲突数量、目标目录、文件名及两侧大小明细，最多展示前 100 项。解压、智能解压、复制及移动入口共用提示。
- 冲突窗口默认选中“取消”，覆盖前明确提示替换后无法自动撤销。
- 进度窗口增加已处理量、总量、平均速度及预计剩余时间；未知总量不猜测剩余时间，计数回退时重置估算，停止进展时隐藏过时估算。
- 取消后保留已处理量并提示可能保留文件，不继续显示剩余时间。
- 按要求在全部内嵌 QSS 开头加入 QWidget:focus{outline: none;}，取消默认焦点轮廓。

## 下载与验证

- x64 / x86 各提供 setup.exe 安装包与 portable.zip 免安装包，附 SHA256SUMS.txt。
- 免安装包完整解压后运行 ZipDesk.exe，附项目 MIT 和第三方许可。
- 双架构各 20 项 CTest 回归；覆盖冲突明细、取消默认按钮、进度估算与计数重置。
- 双架构免安装包在仅系统 PATH 环境下验证 ZIP/7z 创建、校验、解压及内容一致性。

## 当前限制

- 本版仍为预览版且未代码签名；未完成干净系统上的安装、升级、卸载与文件关联全流程验收。
- x86 使用源码编译的 Qt 6.9.1，仅在 WOW64 环境验证，未在原生 32 位 Windows 验收，不支持 Windows 7。
- 速度为当前处理阶段平均值，剩余时间为估算；阶段切换、密码重试及文件系统性能可能改变估算。
- 冲突明细是操作前检查，不代表最终成功/跳过计数。逐项选择、保留两者与完整结果清单仍待实现。
- 取消或失败可能保留部分输出，已覆盖文件不会自动恢复。
