# 青匣 v0.2.3 预览版

继续完善第二阶段解压体验：同名冲突新增“保留两者”。提供 Windows x64 / x86 安装包及免安装 ZIP。

## 更新内容

- 解压、智能解压、资源管理器右键解压和“复制到”的同名冲突窗口新增“保留两者”。原文件保持不变，压缩包中的同名文件另存为“名称 (2).扩展名”这类未占用的编号名称；再次解压会继续使用 (3)、(4)…，不会覆盖之前的副本。
- 实现上先以跳过模式写出无冲突项目，再把冲突项目解到目标目录内的私有临时文件夹并逐个改名移入；原文件始终不以写入方式打开，临时文件夹在成功、失败或取消后清理。
- 完成提示说明按“保留两者”处理，并列出另存的新名称（明细最多 100 项）。
- “移动到”仍要求完整覆盖后核对，不提供保留两者。

## 下载与验证

- x64 / x86 各提供 setup.exe 安装包与 portable.zip 免安装包，附 SHA256SUMS.txt。
- 双架构各 22 项 CTest 回归，新增服务层保留两者测试及 extract_keep、extract_smart-keep 界面场景。
- 双架构免安装包在仅系统 PATH 环境下验证 ZIP/7z 创建、校验、解压及内容一致性。

## 当前限制

- 本版仍为预览版且未代码签名；未完成干净系统上的安装、升级、卸载与文件关联全流程验收。
- x86 使用源码编译的 Qt 6.9.1，仅在 WOW64 环境验证，未在原生 32 位 Windows 验收，不支持 Windows 7。
- 冲突仍按整批选择（全部覆盖 / 保留两者 / 全部跳过）；逐项选择与包含成功、跳过、失败计数的结果清单尚未实现。
- “复制到”选择保留两者后只在状态栏提示完成，暂不列出新名称。
- 取消或失败可能保留部分输出，已覆盖文件不会自动恢复。
