# 青匣 v0.2.4 预览版

继续完善第二阶段解压体验：完成提示显示实际结果统计。提供 Windows x64 / x86 安装包及免安装 ZIP。

## 更新内容

- 解压、智能解压和资源管理器右键解压完成后，提示框显示“共 N 个文件：新写入 a 个文件，覆盖 b 个同名文件，另存 c 个同名文件，跳过 d 个同名文件”。数字来自解压后对目标目录的逐个核对，而不是按计划推算；目录不计入。
- 选择“全部跳过”时，详情里列出被跳过的同名文件（原文件未改动）；选择“保留两者”时继续列出另存的新名称。每类明细最多 100 项。
- 如果解压后有文件未出现在目标目录（例如被其他程序移走或写入失败），标题改为“解压部分完成”并显示警告，详情列出未找到的文件。

## 下载与验证

- x64 / x86 各提供 setup.exe 安装包与 portable.zip 免安装包，附 SHA256SUMS.txt。
- 双架构各 22 项 CTest 回归；服务层新增全新解压、跳过、覆盖与保留两者的计数测试，界面场景校验成功、跳过和保留两者的统计文案。

## 当前限制

- 本版仍为预览版且未代码签名；未完成干净系统上的安装、升级、卸载与文件关联全流程验收。
- x86 使用源码编译的 Qt 6.9.1，仅在 WOW64 环境验证，未在原生 32 位 Windows 验收，不支持 Windows 7。
- 冲突仍按整批选择（全部覆盖 / 保留两者 / 全部跳过），逐项选择尚未实现。
- 解压失败或取消时只提示可能保留部分文件，暂不给出精确计数；“复制到”完成后仍只在状态栏提示。
- 已覆盖的文件不会自动恢复。
