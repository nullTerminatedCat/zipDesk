# 青匣 v0.2.5 预览版

继续完善第二阶段解压体验：同名冲突可以逐个文件选择处理方式。提供 Windows x64 / x86 安装包及免安装 ZIP。

## 更新内容

- 同名冲突提示新增“逐项选择…”。新窗口列出每个冲突文件的名称、所在目录、压缩包内大小与现有文件大小，每个文件可单独选择“保留两者”“跳过”或“覆盖”。
- 顶部提供“全部保留两者 / 全部跳过 / 全部覆盖”批量按钮，可先批量设定再逐个调整；底部实时显示三类数量。
- 默认每个文件都是“保留两者”（不改动原文件），默认按钮为“取消”；取消时不解压任何文件。
- 解压、智能解压、资源管理器右键解压和“复制到”均支持逐项选择；原有“全部覆盖 / 保留两者 / 全部跳过”保持不变。移动仍要求完整覆盖。
- 完成提示中的新写入、覆盖、另存、跳过计数按各文件的实际决定统计，仍来自解压后对目标目录的核对。
- 新增一组线性图标（来自 hippo 图标集，按青匣主色着色）。

## 下载与验证

- x64 / x86 各提供 setup.exe 安装包与 portable.zip 免安装包，附 SHA256SUMS.txt。
- 双架构各 24 项 CTest 回归；服务层新增混合决定（覆盖/跳过/保留两者/无冲突）、整批跳过不误解压其他文件、未指定文件回落到批量策略的测试；界面新增解压与智能解压的逐项选择场景。

## 当前限制

- 本版仍为预览版且未代码签名；未完成干净系统上的安装、升级、卸载与文件关联全流程验收。
- x86 使用源码编译的 Qt 6.9.1，仅在 WOW64 环境验证，未在原生 32 位 Windows 验收，不支持 Windows 7。
- 超过 2000 个冲突时不提供逐项选择，只能整批处理。
- 解压失败或取消时只提示可能保留部分文件，暂不给出精确计数；“复制到”完成后仍只在状态栏提示。
- 冲突提示里的“Show Details...”仍为英文（Qt 翻译未部署）。已覆盖的文件不会自动恢复。
