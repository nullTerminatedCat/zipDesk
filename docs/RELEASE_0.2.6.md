# 青匣 v0.2.6

继续完善第二阶段解压体验：“复制到”完成后也能看到实际结果。提供 Windows x64 / x86 安装包及免安装 ZIP。

## 更新内容

- “复制所选到…”（右键“复制到...”、F5）完成后不再只在状态栏提示，而是弹出与解压一致的结果窗口：显示“共 N 个文件：新写入 / 覆盖 / 另存 / 跳过 / 未找到”计数。
- 按“保留两者”另存的新名称、跳过的同名文件和未找到的文件在详情中列出（每类最多 100 项）；有文件未找到时标题为“复制部分完成”。
- 结果窗口提供“打开目标文件夹”。计数来自复制后对目标目录的实际核对，而不是推算。
- 复制时进度窗口显示“正在复制”；失败或取消时提示“复制未完成 / 复制已取消”，不再显示为“解压”。

## 下载与验证

- x64 / x86 各提供 setup.exe 安装包与 portable.zip 免安装包，附 SHA256SUMS.txt。
- 双架构各 29 项 CTest 回归；新增“复制到”的成功、全部跳过、保留两者、逐项选择和写入失败五个界面场景，校验结果文案、计数、原文件内容及压缩包不变。

## 当前限制

- 程序未代码签名；未完成干净系统上的安装、升级、卸载与文件关联全流程验收。
- x86 使用源码编译的 Qt 6.9.1，仅在 WOW64 环境验证，未在原生 32 位 Windows 验收，不支持 Windows 7。
- 解压或复制失败、取消时只提示可能保留部分文件，暂不给出精确计数。
- 超过 2000 个冲突时不提供逐项选择，只能整批处理。冲突提示里的“Show Details...”仍为英文。已覆盖的文件不会自动恢复。
