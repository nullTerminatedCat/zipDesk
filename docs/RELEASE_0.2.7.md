# 青匣 v0.2.7

继续完善第二阶段解压体验：解压或复制中途失败、被取消时，也能看到目标目录里实际发生了什么。提供 Windows x64 / x86 安装包及免安装 ZIP。

## 更新内容

- 解压、智能解压、资源管理器右键解压和“复制所选到…”失败或取消后，提示窗口会核对目标目录，显示“共 N 个文件：已写出 / 覆盖 / 另存 / 跳过 / 未写出”计数，不再只说“目标目录可能已有部分文件”。
- 另存为新名称、跳过和未写出的文件在详情中列出（每类最多 100 项）；有文件写出时提醒中断时正在写入的文件可能不完整，没有写出任何文件时明确说明目标目录未被改动。
- 已有同名文件只有在大小或修改时间确实变化时才算作“覆盖”；逐项选择和“保留两者”中尚未开始或尚未另存的文件计为“未写出”。

## 下载与验证

- x64 / x86 各提供 setup.exe 安装包与 portable.zip 免安装包，附 SHA256SUMS.txt。
- 双架构各 31 项 CTest 回归；服务层新增取消时计数测试（单文件覆盖取消、逐项选择取消），界面新增解压与智能解压写入失败两个场景。

## 当前限制

- 程序未代码签名；未完成干净系统上的安装、升级、卸载与文件关联全流程验收。
- x86 使用源码编译的 Qt 6.9.1，仅在 WOW64 环境验证，未在原生 32 位 Windows 验收，不支持 Windows 7。
- 失败时被同名文件夹占住的那一项暂不计入总数；“移动”失败仍沿用原有提示；覆盖判断依据大小和修改时间，不做内容比对。
- 超过 2000 个冲突时不提供逐项选择，只能整批处理。冲突提示里的“Show Details...”仍为英文。已覆盖的文件不会自动恢复。
