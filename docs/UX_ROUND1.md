# 青匣体验优化方案 · 第一轮

日期：2026-10-13。目标是让用户第一次打开就知道怎么用，浏览时找得到文件，完成操作后知道发生了什么。以现有 Qt Widgets 架构渐进改进，保留原有文件安全约束。

## 现状与设计方向

当前已经具备基本的青绿色视觉、智能解压、预览、最近记录和结果提示。主要问题是主页操作重复且留白较散、界面字号偏小、列表与路径空间分配不合理、最近记录同名难分辨、搜索无结果缺少指引，部分弹窗配色不统一。

采用浅灰工作区、白色内容面板和青绿色主操作。首页允许较强的品牌色，归档页让文件内容占主要空间。圆角、边框、图标尺寸和键盘焦点保持一致；不靠增加装饰压缩文件列表的可用面积。

## 阶段一：主界面与基础操作（本次实施）

- 首页：收紧布局，突出打开/新建两个主要入口；最近记录展示文件名与所在目录，长路径省略且保留完整提示。
- 归档页：突出解压入口，统一表头和行高，名称列随窗口伸缩；补充压缩包格式、项目数量和展开大小摘要。
- 搜索与导航：长路径不撑大窗口，Ctrl+F 聚焦搜索、Esc 清除；空包与无匹配结果分别提示，无结果提供清除按钮。
- 视觉一致性：统一字号、间距、主辅色，补上键盘焦点，进度弹窗跟随相同配色。
- 验收：现有 19 项回归通过；检查普通和 720×520 小窗口、150% 缩放截图；实际验证搜索清除恢复、目录导航、最近记录重开、预览。
- 交付：本地可运行程序、界面截图、本方案及进度记录。先评审这一轮，不自动替换已发布安装包。

## 阶段二：压缩与解压流程

- 压缩对话框将格式、保存位置作为主要设置，密码、分卷、固实压缩等收入高级区域；输入不合法时就地说明。
- 解压冲突从全部覆盖/跳过扩展到逐项选择与保留两者；展示实际成功、跳过、失败项目以及目标文件夹入口。
- 进度补充已处理量、速度与剩余时间；未知总量明确显示处理中，取消后说明哪些结果已保留。
- 验收：ZIP/7z、密码、同名冲突、取消和部分失败的结果一致，统计来自实际操作而非推算。

## 阶段三：批量与文件安全

- 多压缩包拖入提供明确的批量队列，混合普通文件时先区分打开、压缩与追加，避免静默忽略项目。
- 补齐外部编辑跨包切换、同名文件同时编辑、异常退出后的文件保留验证。
- 验证删除/重命名/替换和分卷输出的取消与失败保护；必要时临时归档成功后再替换源文件。
- 验收：逐项列出结果；失败与取消不能破坏原包；专项故障样本通过后才关闭现有 PRODUCT_PLAN 的安全项。

## 阶段四：可发布质量

- 补齐中英文文案、键盘与高 DPI 验收；格式支持列表与实际读取能力一致。
- 统一版本号与发布说明，x64/x86 构建和包内依赖自动检查。
- 在干净 Windows 环境验证安装、升级、卸载及文件关联；发布前更新 README 截图。
- 深色模式、主题切换、更广格式矩阵放在浅色主流程稳定后，避免同轮扩大验证范围。

## 执行规则

每阶段单独交付并记录验证结果。新界面不能降低文件安全；已有 PRODUCT_PLAN.md 的风险项保留。出现具体缺陷先修复再继续，未测试的系统与场景明确标注。
